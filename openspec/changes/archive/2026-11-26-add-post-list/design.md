## Context

작성 API는 웹 컨트롤러에서 작성 입력 포트와 저장소 출력 포트를 거쳐 메모리에 게시글을 저장한다. 목록 조회에도 같은 계층 경계와 저장소를 사용한다.

## Decisions

- 웹 컨트롤러에서 조회 입력 포트를 호출한다. 조회 유스케이스는 저장소 포트에서 받은 게시글을 ID 오름차순으로 정렬한다.
- 목록 응답은 웹 계층의 전용 응답 타입으로 `id`, `title`, `content`를 명시적으로 공개한다. 기존 작성 API는 `Post`를 직접 반환하며 공개하는 세 필드는 작성 API 테스트로 확인할 수 있다.
- 기존 인메모리 구현에서 조회 시점의 목록을 복사해 전달한다. 기존 구조와 데이터 수명을 따르므로 새 ADR은 작성하지 않는다.
